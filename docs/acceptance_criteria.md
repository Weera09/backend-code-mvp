
# Acceptance Criteria — Mactile MVP

## 1. ข้อมูลโครงการ
- Project Name: Mactile
- Team: Group 4
- Project Type: MVP
- System: Camera Rental and Photography Booking System

## 2. ระบบสมัครสมาชิกและเข้าสู่ระบบ
- [ ] ผู้ใช้สามารถสมัครสมาชิกได้
- [ ] ผู้ใช้สามารถเข้าสู่ระบบได้
- [ ] ระบบสามารถแยกสิทธิ์ Customer, Provider, Photographer และ Admin
- [ ] ผู้ใช้ทั่วไปไม่สามารถเข้าถึงข้อมูล Admin ได้

## 3. ระบบเช่ากล้องถ่ายรูป
- [ ] ลูกค้าสามารถดูรายการกล้องที่เปิดให้เช่าได้
- [ ] ระบบแสดงชื่อกล้อง รุ่น รูปภาพ รายละเอียด และราคา
- [ ] ลูกค้าสามารถเลือกวันเริ่มเช่าและวันคืนกล้องได้
- [ ] ลูกค้าสามารถส่งคำขอเช่ากล้องได้
- [ ] ระบบตรวจสอบช่วงเวลาว่างของกล้องก่อนส่งคำขอ
- [ ] ระบบป้องกันการจองกล้องซ้ำในช่วงเวลาที่ทับซ้อน
- [ ] ลูกค้าสามารถตรวจสอบสถานะการเช่าได้

## 4. ระบบรับจองงานถ่ายภาพ
- [ ] ลูกค้าสามารถดูบริการถ่ายภาพได้
- [ ] ระบบแสดงข้อมูลช่างภาพ ประเภทงาน และราคาเริ่มต้น
- [ ] ลูกค้าสามารถเลือกบริการถ่ายภาพได้
- [ ] ลูกค้าสามารถระบุวัน เวลา และสถานที่ถ่ายภาพได้
- [ ] ลูกค้าสามารถส่งคำขอจองงานถ่ายภาพได้
- [ ] ช่างภาพสามารถตรวจสอบคำขอจองได้
- [ ] ช่างภาพสามารถยืนยันหรือปฏิเสธงานได้
- [ ] ลูกค้าสามารถติดตามสถานะการจองได้

## 5. ระบบจัดการผู้ให้บริการ
- [ ] ผู้ให้บริการสามารถเพิ่มรายการกล้องได้
- [ ] ผู้ให้บริการสามารถแก้ไขรายละเอียดกล้องได้
- [ ] ผู้ให้บริการสามารถกำหนดราคาเช่าได้
- [ ] ผู้ให้บริการสามารถเปลี่ยนสถานะกล้องได้
- [ ] ช่างภาพสามารถจัดการบริการถ่ายภาพได้
- [ ] ช่างภาพสามารถตรวจสอบตารางงานได้

## 6. Admin Dashboard
- [ ] Admin สามารถเข้าสู่หน้า Dashboard ได้
- [ ] Dashboard แสดงภาพรวมจำนวนผู้ใช้
- [ ] Dashboard แสดงรายการกล้อง
- [ ] Dashboard แสดงบริการถ่ายภาพ
- [ ] Dashboard แสดงคำขอเช่ากล้อง
- [ ] Dashboard แสดงรายการจองงานถ่ายภาพ
- [ ] Admin สามารถจัดการข้อมูลผู้ใช้ได้
- [ ] Admin สามารถจัดการรายการกล้องได้
- [ ] Admin สามารถจัดการบริการถ่ายภาพได้
- [ ] Admin สามารถตรวจสอบและจัดการสถานะการจองได้

## 7. การตรวจสอบระบบ
- [ ] ระบบแจ้งเตือนเมื่อกรอกข้อมูลไม่ครบ
- [ ] ระบบแจ้งเตือนเมื่อเลือกช่วงเวลาเช่าที่ไม่ถูกต้อง
- [ ] ระบบไม่อนุญาตให้จองกล้องที่ไม่พร้อมให้เช่า
- [ ] ระบบตรวจสอบสิทธิ์ก่อนแก้ไขข้อมูล
- [ ] ระบบแสดงสถานะการจองได้ถูกต้อง

## 8. ขอบเขต MVP
- [ ] ระบบสามารถแสดงรายการกล้องได้
- [ ] ระบบสามารถส่งคำขอเช่ากล้องได้
- [ ] ระบบสามารถรับจองงานถ่ายภาพได้
- [ ] ระบบสามารถจัดการข้อมูลผ่าน Admin Dashboard ได้
- [ ] ระบบสามารถแสดงสถานะการจองได้

## 9. สิ่งที่ไม่รวมใน MVP
- ระบบชำระเงินออนไลน์
- ระบบจัดส่งกล้องอัตโนมัติ
- ระบบติดตามพัสดุ
- ระบบแชตภายใน
- ระบบแนะนำบริการด้วย AI
