
# Project Charter — Mactile MVP

## 1. ข้อมูลโครงการ
- ชื่อโครงการ: Mactile
- ทีม: กลุ่ม 4
- ประเภท: MVP
- ระบบ: เช่ากล้องถ่ายรูปและรับจองงานถ่ายภาพ

## 2. ภาพรวมโครงการ
Mactile เป็นระบบที่ช่วยให้ลูกค้าสามารถค้นหาและเช่ากล้องถ่ายรูป รวมถึงจองบริการช่างภาพผ่านแพลตฟอร์มเดียว

ระบบประกอบด้วยลูกค้า ผู้ให้บริการกล้อง ช่างภาพ และผู้ดูแลระบบ

## 3. วัตถุประสงค์
1. ให้ลูกค้าค้นหาและเช่ากล้องถ่ายรูปได้
2. ให้ลูกค้าจองบริการถ่ายภาพได้
3. ให้ผู้ให้บริการจัดการกล้องและบริการของตนเอง
4. ให้ช่างภาพจัดการตารางงานและคำขอจอง
5. ให้ผู้ดูแลระบบจัดการข้อมูลผ่าน Dashboard

## 4. ขอบเขตโครงการ

### 4.1 ระบบเช่ากล้อง
- แสดงรายการกล้อง
- แสดงรายละเอียดและราคา
- เลือกวันเช่าและวันคืน
- ส่งคำขอเช่ากล้อง
- ตรวจสอบสถานะการเช่า

### 4.2 ระบบจองงานถ่ายภาพ
- แสดงบริการถ่ายภาพ
- แสดงข้อมูลช่างภาพ
- เลือกวันและเวลาถ่ายภาพ
- ระบุสถานที่และรายละเอียดงาน
- ส่งคำขอจอง
- ตรวจสอบสถานะการจอง

### 4.3 ระบบผู้ให้บริการ
- จัดการข้อมูลกล้อง
- จัดการบริการถ่ายภาพ
- จัดการตารางงาน
- ตรวจสอบคำขอจอง
- อนุมัติหรือปฏิเสธคำขอ

### 4.4 Admin Dashboard
- แสดงภาพรวมระบบ
- จัดการผู้ใช้
- จัดการรายการกล้อง
- จัดการบริการถ่ายภาพ
- ตรวจสอบการเช่าและการจอง
- ติดตามสถานะรายการ

## 5. ผู้มีส่วนเกี่ยวข้อง
- ลูกค้า
- ผู้ให้เช่ากล้อง
- ช่างภาพ
- ผู้ดูแลระบบ
- ทีมพัฒนา กลุ่ม 4 Mactile

## 6. ผลส่งมอบ
- ระบบเช่ากล้องถ่ายรูป
- ระบบจองงานถ่ายภาพ
- ระบบจัดการผู้ให้บริการ
- Admin Dashboard
- เอกสารโครงการ
- เอกสารทดสอบระบบ

## 7. เกณฑ์ความสำเร็จ
- ลูกค้าสามารถดูรายการกล้องได้
- ลูกค้าสามารถส่งคำขอเช่ากล้องได้
- ลูกค้าสามารถจองงานถ่ายภาพได้
- ผู้ให้บริการสามารถจัดการคำขอได้
- ผู้ดูแลระบบสามารถจัดการข้อมูลผ่าน Dashboard ได้
- ระบบแสดงสถานะการจองได้ถูกต้อง

## 8. ข้อจำกัด
- MVP ยังไม่รองรับการชำระเงินออนไลน์
- ยังไม่รองรับระบบจัดส่งกล้องอัตโนมัติ
- การรับและคืนกล้องอาจดำเนินการนอกระบบ
- ระบบเน้นการทดสอบและสาธิตโครงการ

## 9. สรุป
Mactile MVP มุ่งพัฒนาระบบเช่ากล้องถ่ายรูปและรับจองงานถ่ายภาพ โดยรวมกระบวนการค้นหา การจอง และจัดการข้อมูลไว้ในแพลตฟอร์มเดียว เพื่อให้ลูกค้าและผู้ให้บริการใช้งานได้สะดวก
