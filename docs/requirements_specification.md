
# Requirements Specification — Mactile MVP

## 1. ข้อมูลโครงการ
- Project Name: Mactile
- Team: Group 4
- Project Type: MVP
- System: Camera Rental and Photography Booking System

## 2. Introduction

Mactile เป็นระบบเช่ากล้องถ่ายรูปและรับจองงานถ่ายภาพ
ที่ช่วยให้ลูกค้าสามารถค้นหากล้อง เลือกช่วงเวลาเช่า
และจองบริการช่างภาพผ่านระบบ

ระบบประกอบด้วยลูกค้า ผู้ให้เช่ากล้อง ช่างภาพ
และผู้ดูแลระบบ

## 3. User Roles

### Customer
- สมัครสมาชิกและเข้าสู่ระบบ
- ดูรายการกล้อง
- ส่งคำขอเช่ากล้อง
- จองงานถ่ายภาพ
- ตรวจสอบสถานะการจอง

### Provider
- จัดการรายการกล้อง
- กำหนดราคาเช่า
- ตรวจสอบคำขอเช่า
- อนุมัติหรือปฏิเสธคำขอ

### Photographer
- จัดการโปรไฟล์
- จัดการบริการถ่ายภาพ
- กำหนดเวลารับงาน
- ตรวจสอบคำขอจอง
- ยืนยันหรือปฏิเสธงาน

### Admin
- จัดการผู้ใช้
- จัดการรายการกล้อง
- จัดการบริการถ่ายภาพ
- ตรวจสอบการจอง
- ดู Dashboard

## 4. Functional Requirements

### FR-01 User Authentication
ระบบต้องรองรับการสมัครสมาชิกและเข้าสู่ระบบ

### FR-02 Camera Listing
ระบบต้องแสดงรายการกล้องพร้อมรายละเอียด
รูปภาพ ราคา และสถานะ

### FR-03 Camera Rental
ลูกค้าสามารถเลือกวันเช่าและวันคืน
พร้อมส่งคำขอเช่ากล้องได้

### FR-04 Rental Status
ระบบต้องแสดงสถานะคำขอเช่ากล้อง
เช่น Pending, Approved, Rejected และ Returned

### FR-05 Photography Service
ระบบต้องแสดงบริการถ่ายภาพ
ประเภทงาน รายละเอียด และราคาเริ่มต้น

### FR-06 Photography Booking
ลูกค้าสามารถเลือกบริการ
ระบุวัน เวลา สถานที่ และรายละเอียดงานได้

### FR-07 Photographer Management
ช่างภาพสามารถจัดการบริการ
ตารางงาน และคำขอจองได้

### FR-08 Admin Dashboard
ผู้ดูแลระบบสามารถดูภาพรวม
ผู้ใช้ รายการกล้อง และการจองได้

### FR-09 Booking Management
ผู้ดูแลสามารถตรวจสอบ
และจัดการสถานะการจองได้

## 5. Non-Functional Requirements

### Security
ระบบต้องตรวจสอบสิทธิ์ผู้ใช้
และป้องกันการเข้าถึงข้อมูลโดยไม่ได้รับอนุญาต

### Performance
ระบบควรแสดงข้อมูลรายการกล้อง
และบริการถ่ายภาพได้อย่างเหมาะสม

### Usability
ระบบต้องมีหน้าจอที่เข้าใจง่าย
และใช้งานสะดวก

### Reliability
ระบบต้องบันทึกข้อมูลการจอง
และแสดงสถานะได้ถูกต้อง

### Maintainability
ระบบควรแบ่งส่วนการทำงาน
เพื่อให้สามารถแก้ไขและพัฒนาต่อได้

## 6. Business Rules

1. ผู้ใช้ต้องเข้าสู่ระบบก่อนส่งคำขอจอง
2. ลูกค้าสามารถดูข้อมูลการจองของตนเองได้
3. ผู้ให้บริการจัดการข้อมูลตามสิทธิ์ของตน
4. ผู้ดูแลระบบสามารถจัดการข้อมูลทั้งหมดตามสิทธิ์
5. กล้องเดียวกันต้องไม่ถูกจองซ้ำในช่วงเวลาที่ทับซ้อน
6. งานถ่ายภาพต้องตรวจสอบตารางงานของช่างภาพ
7. ระบบต้องตรวจสอบข้อมูลก่อนบันทึก

## 7. MVP Scope

ระบบประกอบด้วย:
- User Authentication
- Camera Listing
- Camera Rental
- Photography Service
- Photography Booking
- Provider Management
- Admin Dashboard

## 8. Out of Scope

- Online Payment
- Automatic Delivery
- Live Chat
- Video Call
- AI Recommendation
- Advanced Review System

## 9. Expected Result

ระบบ Mactile MVP ต้องสามารถ
ให้ลูกค้าค้นหาและเช่ากล้องถ่ายรูป
รวมถึงจองงานถ่ายภาพได้

ผู้ให้บริการสามารถจัดการข้อมูล
และผู้ดูแลระบบสามารถติดตาม
การจองผ่าน Dashboard ได้
